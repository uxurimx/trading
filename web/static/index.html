Leyenda visual

Marcador de precio actual

  • Diamante cian + halo: precio actual. La línea horizontal/vertical marca el nivel. El label muestra el valor exacto.

Niveles (S/R)

  • Verde (resistencia rota / soporte): nivel histórico con presión compradora.
  • Rojo (resistencia / soporte roto): nivel con presión vendedora.
  • Número junto al nivel: cantidad de toques registrados — cuántas veces el precio rozó esa banda (±0.1%). Más toques = nivel más “probado”.
  • Halo de luz alrededor del nivel: energía actual del nivel. verde = flujo comprador dominante · rojo = flujo vendedor · gris = sin presión definida. El brillo crece con la magnitud del flujo (CVD pesado).
  • ⚡ rayo: pulso de liquidaciones cerca del nivel — alguien acaba de ser liquidado ahí. Suele preceder una mecha.
  • Flecha ▲ / ▼: dirección dominante del CVD en la última ventana. ▲ = compradores empujan, ▼ = vendedores empujan.

Barras de momentum (gauges)

  • 6 barras pequeñas verticales: los últimos 6 valores históricos del gauge, agrupados temporalmente. La altura indica magnitud; el color es el del gauge.
  • Línea punteada horizontal: el valor actual sobre las barras — permite leer si está acelerando o desacelerando vs la historia reciente.
  • Coherencia entre barras = tendencia clara. Saltos = volatilidad sin dirección.

Strip vertical (perfil + heat memory)

  • Punto lila / morado: alta concentración de volumen perfil (HVN) o liquidez agresiva en ese nivel. Es zona donde el precio “se pegó” en el pasado reciente.
  • Naranja translúcido (heat memory): dónde estuvo el precio en los últimos minutos. Más opaco = más tiempo. Ajusta la opacidad con el slider 🔥.
  • Bids (verde) / asks (rojo) extendidos: profundidad del libro a cada lado del precio.

Barra de progreso (SL → TP)

  • Naranja translúcido dentro de la barra: dwell por sub-zona — dónde se pasea el precio dentro del rango. Más opaco = más tiempo acumulado en esa banda fina.
  • Verde / rojo / amarillo (BE): color del fill indica si vas en ganancia, pérdida o break-even.
  • Móvil: sólo se muestra el siguiente hito relevante con su color (SL rojo · BE amarillo · TP/hitos verdes).

¿Qué hago con esto?

  • Halo verde fuerte + ⚡ en un nivel arriba → posible squeeze alcista: stops largos por encima se están barriendo.
  • Heat memory denso + nivel rojo → zona de distribución; cuidado con rupturas falsas.
  • Gauges con 6 barras coherentes en una dirección → tendencia sostenida; no es ruido.
  • Dwell concentrado cerca de tu SL → el precio está “masticando” tu stop; considera mover SL o reducir tamaño.
